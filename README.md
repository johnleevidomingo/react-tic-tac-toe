# React Tic-Tac-Toe

The [React tic-tac-toe tutorial](https://react.dev/learn/tutorial-tic-tac-toe) (with time travel), plus the ICS 314 additional challenges.

## Branches

| Branch | Challenge |
| --- | --- |
| `main` | Finished tutorial (time travel) |
| `challenge-1` | `calculateWinner()` uses the win-condition regex instead of a loop |
| `challenge-2` | Reset button |
| `challenge-3` | Computer plays O with `findBestMove()` (win → block → center/corners/edges) |
| `challenge-4` | "Switch to Player {player}" button |
| `challenge-5` | `findBestMove()` uses recursive minimax |
| `challenge-6` | Adjustable board size (rows × columns), win = min(rows, cols) in a row |
| `challenge-7` | Board size can be changed mid-game; pieces keep their row/column |

Each branch builds on the one before it.

## Running

```
npm install
npm run dev
```
